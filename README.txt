STRUKTUR FILE
==============
Code.gs
index.html
script.js
style.css

CARA MEMASANG
=============
1. Buat Google Spreadsheet.
2. Extensions > Apps Script.
3. Buat file Code.gs, index.html, script.js, style.css.
4. Salin isi masing-masing file dari paket ini.
5. Jalankan setup() satu kali.
6. Deploy > New deployment > Web app.
7. Execute as: Me.
8. Atur akses sesuai kebijakan kantor.

CATATAN
=======
index.html menggunakan include() dari Code.gs untuk memuat script.js dan style.css.
